# 基础生产链 Active Spec

> 状态：Active  
> 范围：先行实现和验证的基础生产链，不裁剪 RFC 0001 的完整目标

原版遭遇战开局的指挥中心替换为恒星基地，原版工程师替换为工程船。恒星基地生产工程船，工程船建造发电区和造船厂，造船厂生产护卫舰。原生 `$` 即本模组的能量币，不再存在另一套自定义能量资源。恒星基地与发电区产出能量币，造船、建筑和相关研究均从同一余额支付。研究站产出自定义科研；基础研究仍需按动作价格另外消耗矿物或合金。

贴图由本项目生成，不复制本机游戏或已订阅模组素材。五类单位要有可读取的配置和贴图；是否可玩以游戏内测试为准。自定义资源、科技、阵营差异和巨像状态仍按 RFC 0001 讨论和验证。
