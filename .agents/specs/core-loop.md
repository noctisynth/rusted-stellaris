# 基础生产链 Active Spec

> 状态：Active  
> 范围：先行实现和验证的基础生产链，不裁剪 RFC 0001 的完整目标

原版地图保留原版指挥中心和工程车的开局及建造树；玩家可选建造星际帝国选择器与工程船进入本模组路线。三张专用地图直接以阵营选择器和工程船开局。恒星基地生产工程船，工程船建造发电区和造船厂，造船厂生产护卫舰。原生 `$` 即本模组的能量币，不再存在另一套自定义能量资源。恒星基地与发电区产出能量币，造船、建筑和相关研究均从同一余额支付。研究站产出自定义科研；基础研究仍需按动作价格另外消耗矿物或合金。

贴图由本项目生成，不复制本机游戏或已订阅模组素材。五类单位要有可读取的配置和贴图；是否可玩以游戏内测试为准。自定义资源、科技、阵营差异和巨像状态仍按 RFC 0001 讨论和验证。

原版地图的星际帝国选择器造价为 2000 `$`，使玩家能在保留原版开局的同时及时进入模组生产链。星际帝国的基础经济应优于原版行星经济：发电区花费 850 `$`、每周期产出 12 `$`，且无需资源矿点；其 T2/T3 在同一占地分别产出 24/48 `$`。这些数值是与本机游戏 1.15 原版资源制造仪 T1/T2/T3 的 8/12/20 `$` 每周期对照后的平衡基线，不代表两种建筑的科研和材料门槛相同。原版单位继续可建，混合经济属于允许玩法。实际收入、进入模组路线的用时及完整对局强度仍需游戏内验收。

矿点只建设采矿站，工程船不再建造同名替代建筑。采矿站的矿物是合金铸造厂的持续原料，发电区提供冶炼所需能量；两种资源不足时不能凭空获得合金。采矿站 T2 在第二时代升级，T3 在第三时代升级，矿物处理厂只提供队伍范围的比例加成。
