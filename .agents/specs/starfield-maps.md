# 星域地图基础结构 Active Spec

> 状态：Active  
> 范围：三张地图的可发现、对称出生与基础资源点；不宣称行星机制完成

模组提供 2 人双星咽喉、4 人三臂星域和 8 人破碎银河三张原创 TMX 地图。三臂星域允许大厅关闭一个玩家位以进行 3 人对局。每张地图有星空地形、各队初始指挥中心、工程师、科研船和四艘护卫舰，以及各出生点附近等量的资源池和中央争夺资源池。原版指挥中心由本模组替换为阵营选择器，工程师由本模组替换为工程船。

地图文件由项目脚本生成，贴图为本项目绘制。生成脚本必须可重复运行，地图结构验证要检查各队出生和资源池数量。游戏启动日志至少应发现三张地图；地图能否完整载入、玩家位是否正确、实际对局能否结束，仍需在游戏中验证。

RFC 0001 中的行星节点、咽喉、航道、占领规则和巨像后果属于后续完整星域系统，不能以此基础地图代替。
