# 巨像盟友服役通知

2026-10-09，游戏 1.15 的原生消息范围没有盟友专属广播。巨像完工动作发送建造者与敌方消息，并在一秒后使用 `takeResources_includeUnitsWithinRange_team: allyNotOwn` 向盟友的模组单位发送带标签的内部消息。接收动作只向所属玩家展示盟友文本。

每个接收队伍用隐藏全局资源记录 `eventSource.id`，同一巨像发给该队多个单位时只有首个动作展示消息。改用接收标记之前的首个单位搜索方案没有成功展示盟友消息，已经弃用。所有模组单位自动登记接收标签，单位转换丢失标签后也能重新登记。没有模组单位的队伍缺少接收端，观战者未覆盖。

隔离四队任务地图设队伍 0 与 1 为盟友，队伍 2 与 3 为敌方，由队伍 1 在开局三秒后生成巨像。日志确认玩家队伍 0 显示完整盟友文案。正式配置通过三张专用地图载入。多人联机、同时多个盟友完成巨像、单位转换期间接收及正常对局完工仍需实测。
