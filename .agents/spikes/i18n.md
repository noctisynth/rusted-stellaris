# 中英文原生本地化验证

> 2026-11-05；本机 Steam RW 1.15；只读解析及 `work/i18n-game` 隔离游戏副本。

## 实现与范围

`locales/zh.json`、`en.json` 有 622 条翻译，`bindings.json` 绑定 766 个实际文本位置。765 个为单位/资源模板字段，另外一个是中英并列的模组简介。所有现有非注释中文单位字段均已收录。行星四种状态、17 颗行星的三类巨像结局，以及本方、敌方、盟友公告均在范围内。

每个本地化字段生成默认英文、`_zh` 与 `_en`。引擎 `h.a.c()` 的语言代码和 `bb.b()` 的回退匹配经过字节码核对：强制英文可能使用空代码，所以不能把中文放在默认字段、只提供 `_en`。子配置同时覆盖所有语言，避免继承父单位翻译。语言选择只影响显示；没有增加同步逻辑分支。

`mod-info.txt` 保留品牌标题，简介由语言表生成中英并列的普通字符串，不添加未支持的语言字段。

## 公告与地图能力证据

本机 `game-lib.jar` 使用附带 `javap` 只读核对：

- `game.units.custom.a.a.f.a(...)` 对三个 `showMessageTo*` 字段调用 `custom.ag.a(...)`，再经 `utility.ab` 读取带语言后缀的动态字符串。
- `game.b.a.a(String, bb)` 收集同一属性名下的语言后缀，创建 `bb`。
- `gameFramework.n.f` 对 `map_info.introText` 调用该方法；`n.c` 对 `globalMessage` 及地图文字 `text` 调用对应 LocaleString 解析器。

因此单位公告用 `showMessageToPlayer_zh` 等；TMX 属性用 `introText_zh`、`globalMessage_zh`、`text_zh`。接收对象、触发条件不变。地图 `name`、`id`、`activatedBy`、单位键与文件名保持原值。

三张正式地图当前没有关卡简报、地图公告和地图文字对象，不为翻译新增任务内容；地图上的行星文案来自单位配置。文件名在模组层面的动态本地化未核实，保持原路径。地图生成器按集中中文语言表读取行星显示名。

## 建造、战斗与完整受控短局

```text
uv run --locked python tools/smoke_game_localization.py --game-dir work/i18n-game
```

记录：`work/i18n-match-dfb0e2ca92/`。英文与中文各启动一个隔离短局。临时造船厂变体排队生产一艘原配置 `rsCorvette`，完成动作使用本地化玩家公告。护卫舰用原武器击毁 1 HP 无武装建筑变体。建造前正常二进制存档没有护卫舰，建造后存档有一艘护卫舰，并存在敌方建筑 `destroyed` 事件留下的队伍标记。敌方建筑残骸可能仍在存档对象表内，不能仅凭单位名是否消失判断死亡。

只读观察器确认单人胜利画面使用的引擎 `dq=true`、`dt=false` 状态；不是把调试命令回复 `done` 或多人队伍的 `H` 标记当成单人胜利。两种语言均完成建造、击杀和胜利。探针不改正式单位，只添加临时文件，退出后删除。

此测试特意采用免费生产与弱靶标，确认本次文案变动没有阻断游戏生命周期，**不验证正式经济、平衡或正常时长对局体验**。完整长局、长文排版观感、多人客户端分别选择语言、Android 和 iOS 尚未实测。

## 静态与生成回归

六项自动测试覆盖缺失绑定、重复字段/JSON 键、空翻译、英文残留中文、占位符不一致、默认英文回退、子配置覆盖、地图三类文本与触发器 ID 保持、元数据普通字符串及生成幂等性。单位和地图静态检查通过，构建与 CI 必须运行本地化检查。

与修改前 `HEAD` 比较 175 个单位/公共模板文件，排除显示文本后，所有配置字段一致。68 个编号行星变体的生成器输出与现有玩法一致；重跑生成器并同步翻译后仍通过检查。没有复制第三方模组代码、图片或声音。

术语从本机《群星》英文 `machine_age_l_english.yml` 核对：密语护航舰为 **Riddle Escort**，神秘战巡舰为 **Enigma Battlecruiser**。天机研究所、天机工程、悖论泰坦及自创地图名称的英文是本项目译名，不宣称是原作官方术语；长篇公告的英文由本项目翻译，没有复制原版英文事件全文。
