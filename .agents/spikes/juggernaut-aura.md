# 主宰火力光环验证

2026-10-09，依据 Accepted RFC 0004，主宰完工后添加 `rsJuggernautAuraActive`，附近舰船查询同队和盟友的活跃来源。受益舰型通过 `rsQuantumFleet` 与完工标记筛选，排除带 `rsJuggernaut` 的主宰。巨像、方舟、工程船、建筑和原版单位没有该作战舰队标签，不进入合成动作。

学院训练仍通过 flag 1 管理生命上限与比例，不再单独写火力。公共模板每约一秒从学院 flag 与 650 范围内主宰是否存在合成伤害及攻击间隔，分别写为 1/1.1/1.21 与 1/0.90909，不累乘已有属性。升级清除动态属性后下一次合成恢复对应值。多个来源只作布尔存在判断，不能重复叠加。射程、维修、造舰、激光防御耗能与恢复字段未修改。

主宰增加不可射击的范围指示炮塔，`limitingRange: 650` 与 `showRangeUIGuide: true`。三张地图载入确认配置被接受，实际界面范围圈观感尚待复核。宏展开不支持嵌套动态表达式，逻辑中也没有可用的 `abs` 函数，初次尝试已被载入检查发现并替换为直接表达式与定期重算。

## 正常存档回归

通过记录 `work/juggernaut-aura-9807136a/`，对应已忽略的日志和唯一二进制存档。专项探针临时禁止交火与碰撞，只验证状态：

- 基线没有伤害或间隔加成，单艘盟友主宰出现后九个舰船记录为伤害 1.1、间隔约 0.9091。
- 650 边界附近同时放置舰船，加入同位置的第二艘主宰后记录数量和倍率保持不变。测试关闭碰撞以免位置漂移影响边界判断。
- 本队学院训练完成后六个受益舰体成为伤害 1.21，光环间隔不变。其余训练但不在范围内的舰船只有学院伤害加成。
- 巡洋舰实际执行 T2 改装并保留组合加成，正常保存、读档、继续运行后倍率和数量保持不变。
- 两艘主宰离开后范围射速与光环伤害撤销，学院训练仍保留；返回后恢复。
- 学院消失后组合伤害撤销为光环单独的 1.1；两艘主宰死亡后倍率恢复基础值，随后正常存读档仍保持撤销状态。
- 原型脚本现整理为 `tools/smoke_game_auras.py`，仅允许在仓库 `work/` 下运行并恢复临时配置。指令为 `uv run --locked python tools/smoke_game_auras.py --game-dir work/game-sandbox`。

引擎把 1.1 存为单精度，间隔的实际记录为 0.9090908765792847。测试按该精度核对，不用 Python 双精度结果的字节直接断言。死亡对象可能仍作为残骸保存在对象列表，撤销按动态属性记录确认，不能仅凭名字仍存在判定来源存活。

## 验证边界

另做的 T2 战列舰战斗对照没有形成有效交火，两侧记录均保持满血，不能据此宣称战斗增益已验收。固定成本战斗、完整对局、多人联机、移动端以及选中圈的实际显示尚待实测。本次已验证的是游戏配置载入、来源查找、组合属性、升级与正常二进制存读档。
