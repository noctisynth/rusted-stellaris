# 遭遇战地图行星触发器探针

2026-10-01，游戏 1.15 隔离副本，基于双星咽喉地图。此文件记录技术证据，尚未接受为多数胜利机制。

本机内置任务地图使用 `unitDetect`、`unitAdd`、`objective` 与 `winCondition=requiredObjectives`。先在遭遇战地图隔离副本放置一个 `unitAdd`，延迟 2 秒生成本队护卫舰；12 秒存档出现新护卫舰，证明遭遇战执行普通触发器。再预置一座本队 `rsColony`，添加覆盖全图、限制 `team=0`、`unitType=rsColony`、`minUnits=1` 的 `unitDetect`，让另一个 `unitAdd` 由其 `activatedBy` 触发。存档出现预置殖民地 (850,910) 与由检测器生成的科研船 (1210,1610)，同时保留独立的延迟护卫舰 (1010,1610)。可确认遭遇战会按队伍和殖民地类型检测，并触发后继动作。

探针只在忽略的 `work/game-sandbox` 中运行，没有将测试舰或触发器放进正式地图。它尚未证明 `unitDetect` 在失去殖民地时会撤销、`warmup` 是否能实现持续控制时间、任务地图的 `objective` 能否为多人遭遇战判胜，也没有证明动态移除破碎/封存行星后的多数门槛。正式设计仍要求分值只对应现有殖民地，且不能在所有行星失效时僵局。后续应在隔离副本分别做撤销与重新触发、计时、地图胜利检测，成功后再修改三张正式地图。
