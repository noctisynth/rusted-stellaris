# 终局成果公告技术核对

> 状态：配置已载入，触发与联机显示待实测

已核对本机《群星》简体中文文本。`utopia.84` 与 `utopia.86` 分别把科学枢纽写成建造方的启蒙里程碑和其他帝国的技术优势预警；`utopia.4005` 与 `utopia.4010` 分别以建造方掌握恒星、旁观者看到光芒消失描写戴森球。`fedev.9500` 强调主宰能在前线造舰维修并改变进攻范式；`over.10` 着重量子弹弓最终精校和投入运行。`feda.1` 是巨型船坞初期框架事件，不是最终竣工，不能当作完工原文。巨像的 `apoc.120` 是巨像计划研究完成，也不是巨像实际服役。物质解压器、泰坦和悖论泰坦舰没有找到可直接对应的最终完工事件，文案只沿用该系列的叙述风格。

模组消息需要对所有接收者成立，且无法代入《群星》事件中的帝国和星系变量。改写重点是保留事实与视角差异，并使用克制、庄重的语气；不复制原版长段落。

追加核对：《群星》泰坦的 `TECH_UNLOCK_TITAN_CONSTRUCTION_DESC` 强调旗舰与多种武器，悖论泰坦舰的 `TECH_UNLOCK_FETITAN_CONSTRUCTION_DESC` 强调移动堡垒与高防护；它们是解锁说明，不是舰船完工事件。`apoc.120` 是巨像计划研究完成，分一般、军国、和平、排外、唯物、机械与蜂巢等文本；本模组只有常规、机械、蜂巢三个阵营，不映射未实现的思潮分支。`planet_destruction.101`、`.301`、`.210` 分别提供地爆天星、中子灭杀、安乐天使造成后果时的叙述参考。

当前实现对三种巨像武器采取两个时机：专用地图由中立行星的 `tookDamage(withTag=...)` 转换动作发送后果公告，发射动作只向建造方报已发射；普通地图没有行星对象，由两个区域打击动作在充能完成后向全体玩家报已发射。研究文本直接附在三个互斥、同价且共用 `rsTechColossus` 的研究动作上，避免研究站轮询队伍标签时的重复提示。隔离副本三图载入成功；行动实际完成、受击后消息显示与多人同步仍待观察。

《铁锈战争》1.15 的单位配置支持 `autoTriggerOnEvent: completeAndActive`。游戏开发者的 [1.15 模组参考资料](https://corrodinggames.com/modding-reference-beta)列出 `showMessageToAllPlayers` 和 `showMessageToPlayer`。模组现让最终单位在完成事件中发一条全局公告，并给建造方发一条专属消息。训练成精锐时不继承该动作，悖论泰坦改装时替换基础泰坦的动作。

180 个单位的静态检查及隔离副本三张地图载入通过。尚未观察到建造完工时的游戏界面，也未核对两人联机接收、保存后重载或双方同时完工的显示顺序。`showMessageToAllPlayers` 是否包含观战者、是否能按接收者既有资产分叉文案，均未验证；当前全局文案对任何接收者都成立。
