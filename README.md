# Rusted Stellaris

把星际帝国的扩张与舰队战争带入《铁锈战争》。Rusted Stellaris 是《群星》题材的非官方同人模组：从建设经济、研究科技起步，升级星港，组建舰队，争夺星域，并走向巨构与巨像时代。

## 模组内容

- **三种帝国开局**：常规帝国、机械智能与蜂巢思维。
- **星际经济与科技**：发展能量、矿物、合金、科研与战略资源，逐步解锁建筑和舰船。
- **舰队与星港**：从护卫舰、驱逐舰到巡洋舰、战列舰、泰坦和主宰，配合星港升级、维修设施与舰队学院。
- **巨构与巨像**：体验量子弹弓等后期设施，以及碎星、封存和中子灭杀等行星结局。
- **三张星域地图**：双星咽喉（2 人）、三臂星域（4 人）和破碎银河（8 人）。
- **四首原创纯音乐**：《最后的星光》《光之航迹》《银河彼岸》《星云回声》，在使用本模组单位时进入专属播放列表。

## 下载与游玩

- **Steam 玩家**：前往 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3813493737)订阅，在游戏模组列表中启用 **Rusted Stellaris**。
- **手动安装**：从 [GitHub Releases](https://github.com/noctisynth/rusted-stellaris/releases) 下载 `.rwmod`。电脑版也可将其作为 ZIP 解压到游戏的 `mods/units/RustedStellaris/` 目录，确保 `mod-info.txt` 直接位于该目录下，然后重启游戏并启用模组。

同一模组只启用一份，避免工坊版与手动安装版重复加载。第一次游玩建议选择双人地图「双星咽喉」，从发电、采矿、合金生产和研究站开始发展。

详细玩法与已知问题见 [试玩指南](docs/试玩指南.md)。联机时请确保所有玩家使用相同版本和同一份模组文件。

## 当前状态

首个计划发布版本为 **0.1.0**，项目仍会持续完善。当前已在电脑版游戏 1.15 上进行载入与部分对局验证；完整玩法和平衡验收尚未完成，多人与移动端兼容性仍待实测。原版地图也可尝试星际帝国路线，但布局和体验与专用地图不同。

遇到问题可在 [GitHub Issues](https://github.com/noctisynth/rusted-stellaris/issues) 反馈，请附上模组版本、游戏版本、地图名称、操作步骤和截图。
