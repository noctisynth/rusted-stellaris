# 开发版试玩指南

当前开发版已同步至本机正版游戏。其他贡献者可按《铁锈战争》的模组安装方式，将本仓库的模组文件和三张地图导入同一个模组。启动或重启游戏后，在模组列表启用 **Rusted Stellaris (Development)**，选择双星咽喉、三臂星域或破碎银河地图即可试玩。建议先用双人图熟悉流程。

开局选择常规帝国、机械智能或蜂巢思维。工程船可以建设发电区、矿物采集、研究站和造船厂；研究站逐步解锁舰体、星港与其它科技。原版地图仍保留原版开局和单位路线，可另行尝试加入星际帝国路线。打包生成的 `.rwmod` 文件也包含全部三张地图，但压缩包的直接导入流程尚未单独验收；当前本机使用已同步的目录版。

建议先重点观察：发电区是否增加原生 `$`、矿物与合金能否周转、研究后造船厂是否解锁、星港升级与维修、舰队轨道轰炸、AI 是否持续建造和进攻。三张地图已通过本机游戏 1.15 的载入检查；隔离对局还验证了部分传送、维修、巨像结局和 AI 扩张，但大量玩家按钮与资源扣费仍需亲自对局确认。

当前已知未完成的核心部分包括：多数关键星系持续控制的第二胜利条件、完整行星占领与计分、部分巨构及舰船的实战验收、原版单位的平衡、多人与手机版兼容。首都失守后的队伍退出机制已接入专用地图，但最后敌方首都被战斗摧毁时的胜利界面仍待实测。遇到问题时，请记录地图、阵营、执行步骤、预期与实际结果，便于在项目中复现和修复。
